# KPU Dormitory Management Information System (DMIS)

A final-year university project built for the Kabul Polytechnic University dormitory and implemented for real use in the dormitory.

## Project context

This system was developed as a three-person university team project.

### Team and roles

- **Wais Alizada — Lead Developer / primary implementer**
- **Ali Shah Safdari — Team member**
- **Mhammad Mahdi Nazari — Team member**

The original project metadata in `package.json` lists all three team members. This restored repository documents my contribution without claiming that the project was completed by one person.

## Main modules

- Student and dormitory administration
- Office management
- Goods and inventory management
- Food/feed management
- Authentication and role-based access
- User management and password recovery
- Reports and operational workflows

## Technology

- Node.js
- Express.js
- MongoDB / Mongoose
- EJS
- Passport
- JWT
- Express Session
- Nodemailer
- Bootstrap / custom CSS

## Public restoration note

This repository is being restored from the original final-project archive. The full project was later uploaded to another team member's GitHub account in a small number of commits, so that public history does not preserve the original collaborative development history.

For security and privacy, this restoration does **not** publish:

- real email passwords or application secrets
- JWT/session secrets
- student-uploaded photos or other personal student data
- unnecessary generated/vendor binary assets

See `.env.example` for safe local configuration.

## Academic significance

This was my final university project. I served as the lead developer and primary implementer, and the system was actually deployed/used for the university dormitory rather than remaining only a classroom prototype.
