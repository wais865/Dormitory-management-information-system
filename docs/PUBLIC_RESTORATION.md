# Public restoration

This repository is a cleaned restoration of the original KPU Dormitory Management Information System final-year project.

The original team consisted of Wais Alizada, Ali Shah Safdari, and Mhammad Mahdi Nazari. Wais Alizada served as lead developer / primary implementer.

The public restoration intentionally removes credentials, student-uploaded photos and personal data. It also avoids inventing or rewriting historical Git commits: the restored code is committed as a restoration, while the team nature of the original project is documented explicitly.
